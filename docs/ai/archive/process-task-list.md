# Process Task List — Web App Roadmap

## Goal
Turn a raw task list into a **prioritized, phased roadmap** across tracks (Auth, Billing, App Core, Landing/SEO, Infra, QA), clear for a junior developer.

---

## Instructions
1. **Prioritization** — Mark tasks High / Medium / Low.  
2. **Dependencies** — Note blocking sequences (e.g., Auth before gated features; Stripe webhooks before entitlements).  
3. **Milestones/Sprints** — Group into 1–2 week sprints or milestones; allow parallel tracks if feasible.  
4. **Release Criteria** — Define DONE gates: tests green, a11y check, Core Web Vitals targets met, billing works, analytics logged.  
5. **Formatting** — Output as phases/sprints with checklists. Include a summary table.

---

## Target Audience
A **junior developer** should be able to follow execution order and understand trade‑offs.
