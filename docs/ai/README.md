# AI Workflow Documentation

This directory contains the guidelines and standards for building software with Antigravity.

## Core Workflow

See [ANTIGRAVITY_WORKFLOW.md](ANTIGRAVITY_WORKFLOW.md) for the complete guide on how to work with the AI agent.

## Directory Structure

*   **`guidelines/`**: The source of truth for all standards.
    *   [prd_standards.md](guidelines/prd_standards.md): How to write Product Requirements Documents.
    *   [coding_standards.md](guidelines/coding_standards.md): Code quality, stack, and testing rules.
    *   [project_planning.md](guidelines/project_planning.md): How to plan projects and break down tasks.
*   **`archive/`**: Old prompt-based recipes (deprecated).

## Usage

When starting a task, direct the agent to specific guidelines:

*   "Read `docs/ai/guidelines/prd_standards.md` and help me draft a PRD."
*   "Read `docs/ai/guidelines/coding_standards.md` before writing any code."
